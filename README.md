# NLP Interview Prep

Мобильный справочник для итогового NLP-мока: **198 вопросов, 42 главы, 198 коротких ответов**.

## Использование

- Нажми на вопрос, чтобы раскрыть/скрыть ответ.
- Нажми «Отметить», чтобы отметить выученный вопрос.
- Используй поиск и фильтры «Все / Не знаю / Знаю».
- «Экспорт» сохраняет прогресс в JSON. На другом устройстве выбери «Импорт» → «Объединить» (без потери уже имеющихся галочек) или «Заменить».
- Светлая/тёмная тема сохраняется в браузере.

## Как запустить

### Самый быстрый просмотр

Открой `index.html` в браузере. Все вопросы и ответы встроены в файл и работают без интернета. **Внимание:** сохранение `localStorage` при открытии как `file://` не гарантировано; для надёжного прогресса используй стабильный HTTPS-адрес.

### Бесплатное размещение на GitHub Pages

1. Создай новый репозиторий GitHub, например `nlp-interview-prep`.
2. Загрузи **содержимое** этой папки (`index.html`, `sw.js`, `manifest.webmanifest`, иконки). `template.html` и `answers.tsv` не обязательны для публикации.
3. В `Settings → Pages → Build and deployment` выбери `Deploy from a branch`, ветку `main`, папку `/(root)`.
4. Открой адрес `https://<username>.github.io/nlp-interview-prep/` (публикация может занять время).
5. На Android в Chrome: меню → «Установить приложение» или «Добавить на главный экран». На iPhone в Safari: «Поделиться» → «На экран Домой».

После первого **успешного открытия на HTTPS** приложение сохраняет интерфейс и ответы в офлайн-кэше через service worker. Для обновления приложения после изменения `index.html` желательно повысить версию `CACHE` в `sw.js`.

### На компьютере без GitHub

Из папки приложения запусти `python -m http.server 8000`, потом открой `http://localhost:8000`. Галочки будут храниться для этого локального адреса; Service worker доступен также на localhost в современных браузерах.

## Важно о данных

- Прогресс сохраняется в **localStorage данного браузера и адреса**. Смена устройства/браузера/домена не синхронизирует его автоматически.
- При очистке данных сайта или в приватном режиме галочки могут исчезнуть. Пользуйся резервным экспортом JSON.
- Экспортируемый файл содержит только список ID отмеченных вопросов, не содержит персональных данных.
- Если приложению отказано в persistent storage, оно покажет предупреждение.
- Публикация в **публичном** репозитории делает тексты вопросов и ответов общедоступными. Это не персональный аккаунт.

## Состав

- `index.html` — приложение, со встроенными вопросами и ответами; работает как самостоятельный HTML.
- `answers.json` — редактируемая база 42 глав и 198 ответов.
- `sw.js`, `manifest.webmanifest`, `icon-*.png` — офлайн/PWA-часть.
- `answers.tsv` — исходные авторские ответы в порядке ID (для редактирования).
- `questions_source.json` — исходные вопросы из Excel.
- `template.html`, `build.py` — сборка HTML из JSON.

При редактировании `answers.json` запусти `python build.py`, чтобы перестроить `index.html`. Для опубликованного PWA также увеличь версию в `sw.js`.

## Качество ответов

Ответы написаны как краткие устные заготовки, а не как исчерпывающие технические статьи. Среди 198 вопросов есть неоднозначные формулировки: в ответах отмечено, где исходную предпосылку стоит оспорить на интервью. Перед собеседованием полезно прогнать сложные темы голосом.
